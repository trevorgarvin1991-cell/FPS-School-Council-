Using the council site

This site shares Frankford Public School Council information, current event planning, documents, and ways to support school fundraising.

Event workspace

Each event workspace uses tabs to organize planning information and keep teams coordinated.

  • Floor Plan: view locations, select a marker for details, and drag to pan the map.
  • Schedule & Events: see event timing and participating stations.
  • Tasks: view planning tasks and their current status.
  • Resources & Members: find key contacts and council information.
  • Budget: review event funding and budget information.

General documents

Open Documents from the site header for council-wide files that are not tied to a single event.

  • Everyone can open shared documents.
  • Signed-in council members can add supported documents up to 10 MB.
  • Signed-in council members can remove uploaded documents.

Donations

Use the Donate link in the site footer to access the donation page.

  • Scan the QR code to open the donation page on a phone.
  • Use the donation request letter to share fundraising details.
  • Contact the school office to arrange a donation.

Council member access

The site is viewable without an account. Select Sign in in the main header when you need to make an approved change.

  • Document uploads and removals require a council account.
  • Budget changes and task creation or removal require a council account.
  • Use Sign out when finished on a shared device.

Accessibility audit

This site is designed to meet WCAG 2.2 Level AA. This is an accessibility target, not a formal certification.

  • Checked page titles, heading order, landmarks, image text alternatives, link text, and external-link safety.
  • Added skip-to-content links and visible keyboard focus indicators on every public page.
  • Added accessible names for form controls, including event, budget, task, sign-in, and document-upload controls.
  • Tested keyboard operation for the event workspace tabs and analytics access controls.

For accessibility guidance, see the WCAG - Quick reference guide.

Privacy and support

The site records a persistent browser identifier, visit time, coarse device type, and selected action labels or destinations to understand site usage. It does not record form values, URL query strings, names, IP addresses, or referrers. Council accounts provide an email address for sign-in, and change logs record the account, action, item or task name, and time.

Council documents, task attachments, and receipts are restricted to signed-in council members. Do not upload student records, health information, personal contact details, payment information, or other sensitive personal information.

The site uses Supabase for authentication, data, and file storage, and loads services such as SharpSchool, jsDelivr, GitHub, and QRServer. These services may receive standard connection details such as an IP address and browser information.

For questions about personal information or requests to access or remove it, contact the school office.

Printed materials: Vendor banners, raffles, and other materials are printed using a Canon TC-20 printer and PosterArtist.
